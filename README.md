## Règles de travail

- On travaille sur la branche `develop` (branche par défaut).
- Chaque personne modifie en priorité **ses propres fichiers**.
- Avant de commencer à travailler : *pull* pour récupérer le travail des autres.
- On fait des *commits* petits et fréquents, avec un message clair.
- En fin de projet, le chef d'équipe ouvre **une pull request de `develop` vers `main`** : c'est le rendu final.
